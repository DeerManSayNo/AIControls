# Prompt 收藏库（独立模块）— 设计规格

日期：2026-05-04  
状态：已确认（待实现计划）

## 背景与目标

在 AIControls 中新增一个与 `skills/mcp/rules` **完全解耦**的本地功能：Prompt 收藏库，用于管理和复用常用 prompt 文本。核心工作流是：**应用内新建 → 列表检索 → 一键复制**。

## 非目标（Out of Scope）

- 不作为 `skills/mcp/rules` 的一种资产类型，不进入现有扫描/分类/预览链路
- 不做全局快捷键剪贴板收藏、不做系统分享入口、不做拖拽导入（后续迭代再加）
- 不将“图片/文档”作为二进制附件主存储（本期的类型是“目标输出类型”，非素材本体）

## 关键产品约束（已拍板）

- **入口**：侧栏新增一级入口 `Prompt 库`
- **主分类**：固定 4 类 Tab：图片 / 代码 / 文档 / 纯文本
- **“类型”语义**：表示 **prompt 的目标输出类型**；每条收藏的主内容永远是文本 prompt
- **主动作**：列表右侧固定按钮 **复制**，永远复制该条目的 `prompt` 文本
- **组织方式**：文件夹粗分组 + 标签细筛 + 搜索
  - 文件夹：默认自动归档到与主分类一致的根文件夹（图片/代码/文档/纯文本）
  - 允许在每个主类下创建子文件夹
- **字段**：
  - 必填：标题（title）、prompt 文本（prompt）、标签（tags，多选）、备注（note）
- **存储**：纯本地；**单文件 JSON**（位于 Tauri `app_local_data_dir`）
- **体量预期**：200–2000 条

## 信息架构（IA）

### 侧栏

- 新增导航项：`Prompt 库`

### Prompt 库页面布局

- **顶部**：页面标题 + `＋ 新建收藏` 按钮
- **Tab**：图片 / 代码 / 文档 / 纯文本（固定）
- **左侧栏（页面内）**：
  - 文件夹树：默认聚焦当前 Tab 的根文件夹；可切换子文件夹
  - 标签筛选：多选（常用标签可快速点选）
- **主内容区**：
  - 搜索框：按标题 / prompt / 标签 / 备注（实现可分期，至少标题 + prompt + 标签）
  - 紧凑列表：每行显示类型图标、标题、标签（最多 2 个 + “+N”）、右侧固定 `复制` 按钮
  - 点行打开右侧详情抽屉
- **右侧详情抽屉**：
  - Prompt 预览（可折叠）
  - 编辑：标题、prompt、标签、备注、移动到子文件夹
  - 删除

## 列表与交互细则

### 列表（紧凑密度，变体 A）

每行：
- 左侧：类型 icon（图片/代码/文档/纯文本）
- 中部：标题（主）；标签 chips（最多 2 个 + “+N”）
- 右侧固定：`复制`

交互：
- 点击 `复制`：复制该条的 `prompt`
- 点击行：打开详情抽屉（不触发复制）

### 新建收藏

入口：
- 页面右上 `＋ 新建收藏`

默认值：
- `type` 默认取当前 Tab
- `folderId` 默认对应 type 根文件夹；可选切换到该 type 下的子文件夹

表单字段（v1）：
- 标题（必填）
- prompt 文本（必填，多行）
- 标签（必填，多选，可新建）
- 备注（必填，多行）

提交结果：
- 保存后出现在当前列表（按排序规则）

## 数据模型（v1）

### PromptItem

- `id: string`（UUID 或类似）
- `type: "image" | "code" | "doc" | "text"`
- `title: string`
- `prompt: string`
- `tags: string[]`（非空）
- `note: string`（非空）
- `folderId: string`（默认=`type` 根文件夹；仅允许移动到同 `type` 的子文件夹）
- `createdAt: number`（ms）
- `updatedAt: number`（ms）

### LibraryFile（单文件 JSON）

- `version: number`
- `folders: Folder[]`
  - 预置 4 个根 folder：image/code/doc/text
  - 子文件夹：`parentId` 指向同 type 根或其子节点
- `items: PromptItem[]`

## 错误处理与数据安全

### JSON 写入可靠性

为避免半写坏文件：
- 写入临时文件（同目录）
- fsync / flush（视平台能力）
- 原子重命名覆盖正式文件

### 兼容与演进

- `version` 字段用于后续 schema 迁移
- 读取失败时提供清晰错误提示，并保留原文件以便手工恢复

## 测试策略（实现阶段）

- **单元测试**：
  - schema 校验（必填字段）

  - 编辑/删除后列表与抽屉状态正确
